# Image Processor

Консольное приложение на C++20 для применения графических фильтров к BMP-изображениям.

Поддерживается 24-битный BMP без сжатия и таблицы цветов, с заголовком `BITMAPINFOHEADER`.
Чтение, запись и обработка изображений реализованы без сторонних графических библиотек.

## Сборка

Нужны CMake 3.16 или новее и компилятор со стандартной библиотекой, поддерживающей C++20.

```bash
git clone https://github.com/aaaaa669/Image-Processor.git
cd Image-Processor
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

## Использование

```bash
./build/image_processor input.bmp output.bmp -neg
```

Первый аргумент — путь к исходному изображению, второй — путь к результату.
Фильтры применяются в порядке перечисления:

```bash
./build/image_processor input.bmp output.bmp -crop 800 600 -gs -blur 2
```

| Фильтр | Действие |
| --- | --- |
| `-crop width height` | Обрезка верхней левой части изображения. Размеры должны быть положительными целыми числами. |
| `-gs` | Преобразование в оттенки серого. |
| `-neg` | Негатив. |
| `-sharp` | Повышение резкости. |
| `-edge threshold` | Выделение границ с заданным порогом. |
| `-blur sigma` | Гауссово размытие. Сигма должна быть положительной. |
| `-crystal` | Кристаллизация: изображение разбивается на одноцветные области вокруг выбранных центров. |

Если фильтры не указаны, программа сохраняет изображение без изменения пикселей.
Запуск без аргументов выводит справку:

```bash
./build/image_processor
```

## Тесты

Тесты включены в сборку по умолчанию:

```bash
cmake --build build --target check_image_processor
```

Чтобы собрать только приложение, при настройке CMake добавьте `-DBUILD_TESTING=OFF`.

## Состав проекта

- `Image.h`, `Image.cpp` — изображение и цветовые каналы.
- `BMPwork.h`, `BMPwork.cpp` — чтение и запись BMP.
- `Filters.h`, `Filters.cpp` — фильтры.
- `main.cpp` — обработка аргументов командной строки и запуск фильтров.
- `test.cpp` — тесты изображений, фильтров и работы с BMP.

Для тестов используется включённая в `third_party/catch` библиотека Catch2.
Её лицензия находится в [third_party/catch/LICENSE.txt](third_party/catch/LICENSE.txt).
